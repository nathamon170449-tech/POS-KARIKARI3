# สยามสมาร์ท POS (Siam Smart POS & Accounting สำหรับ SME ไทย)

ระบบขายหน้าร้าน (POS) + จัดการสต็อกแบบ FIFO + อ่านสลิปโอนเงิน/ใบเสร็จ + วิเคราะห์อัตราส่วนทางการเงิน 12 ตัว สำหรับธุรกิจ SME ขนาดเล็ก (1-5 พนักงาน)

## วิธีติดตั้งและรันบนเครื่องของคุณ
1. ติดตั้ง [Node.js LTS](https://nodejs.org/) (เวอร์ชัน 20 ขึ้นไป)
2. แตกไฟล์ ZIP แล้วเปิด Terminal / Command Prompt ในโฟลเดอร์โปรเจกต์:
   ```bash
   npm install
   ```
3. รันชุดทดสอบความถูกต้องของสูตรบัญชีและอัตราส่วนทางการเงิน (Unit Tests):
   ```bash
   npm test
   ```
4. เริ่มต้นรันเซิร์ฟเวอร์:
   ```bash
   npm start
   ```
5. เปิดเบราว์เซอร์ไปที่ `http://localhost:3000` (หรือเปิดไฟล์ `public/index.html` เพื่อใช้งานโหมดจำลองฐานข้อมูลในเบราว์เซอร์ได้ทันที)
